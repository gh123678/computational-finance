# 2019 年开发期研究记录

> **2026-09-28 口径更新：** 修正曾用名缺档的错误排除后，三因子收益为 -9.67%、最大回撤 31.47%，零成本收益 13.29%，排名缓冲收益 -6.32%。最新明细以 `output/development_2019/` 为准；以下正文保留当时审计过程，旧数值不再作为当前结果。

本轮保持已登记的三因子方向、20 只股票、每周调仓、100 万元、费用与执行规则；没有依据新一年收益调参。2016—2019 年各抽一个交易日验证行情、复权、涨跌停与停牌接口可返回数据；抽查不等于历史完整。随后完整下载 2019 年及上年末预热。

## 结果

数据覆盖 2908 只历史主板 A 股、812752 条日线；2018-11-01 至 2019-12-31 共 286 个交易日。评价从 2018-12-28 初始现金基线开始，2019-01-02 首次执行，全年 244 个交易日。各年均独立从 100 万元开始。

| 情景 | 2019 收益 | 最大回撤 |
|---|---:|---:|
| 三因子等权，10 bp 滑点 | -7.67% | 30.85% |
| 零交易成本诊断 | 15.76% | 20.41% |
| 排名缓冲 40 | -5.79% | 29.16% |
| 三因子，30 bp 滑点 | -23.49% | 38.97% |
| 三因子，50 bp 滑点 | -36.41% | 46.15% |

基线费用及滑点共 226116.11 元，缓冲候选为 216056.84 元，减少 4.45%；基线成交 1965 笔，缓冲为 1908 笔。2019 与 2020 的同一诊断均说明：退出排名 40 的缓冲不足以解决高换手。

不能把零成本的正收益当作可执行优势；也不能因某个单因子在这一年较好就把它选为实盘方案。两年结果是开发样本，不能替代多年连续持仓、验证期和封存测试。

## 数据边界

- 主板数据含 2144 项标准分红送转事件。另发现九项复权变化；两项以发行结果原文补登记，其余七项已找到配股发行日程，最终除权结果原文仍待补齐，见 [公司行动核验](2019-corporate-action-audit.md)。这七项继续执行 20 日价格因子隔离；未知持仓复权变动仍会中止回测。
- 263 条主板日线缺少涨跌停字段，均为 001914.SZ 的历史记录，未进入任何一组历史目标名单；未推算补填。代码变更、名称区间与数据商历史映射仍是股票池审计事项。
- 现有历史名称缺口、行业区间发布版本、日线开盘成交近似、固定 20% 红利税、配股不认购及退市零回收情景仍保留，不能把账本核验通过解释成实盘条件满足。
