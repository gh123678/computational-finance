# 完整本地备份

本项目的代码、文档及作业材料保存在主分支；本地数据缓存、研究输出、临时文件和 Python 环境包含在[完整本地备份](https://github.com/gh123678/computational-finance/releases/tag/local-backup-2026-10-27)中。

下载全部 `full-backup-*.zip` 后解压到同一目录。每个 ZIP 都是独立压缩包，内部保留项目相对路径。`manifest.json` 记录每个文件所在的压缩包、大小及 SHA-256；`SHA256SUMS.txt` 用于验证压缩包本身。

备份排除私有凭据、密钥、Git 内部数据及重复的发布工作副本。仓库保持私有。Python 环境作为本机快照保留，跨机器使用时建议根据依赖文件重新创建环境。

本次按用户要求统一了项目说明、脚本和报告中的称呼，未重新计算实验或改变研究结论。原始公告正文保留原文。部分历史冻结清单中的哈希指向文字清理前的字节；本次下载副本以发布附件的清单为准，文字修改记录见 `2026-10-27-editorial-changes.json`。
