# 五年统一版本复核（2026-09-28）

2016—2020 年现有结果已统一到当前研究代码。2016 已使用该版本；本次重跑 2017—2020 年各九组实验，并完成年度账务核验。旧输出完整保存在 `output/development_comparison/before_unified_20260928/`，原始行情未修改。

## 复核证据

- 原始输入文件与各自下载清单的校验值一致。
- 独立从行情重算 24,675 个入选股票／信号日窗口：20 日动量、5 日反转、20 日低波动和成交额均在数值容差内一致。复权数据的窄范围修正仍复用既有修正规则，因此不是完全独立的数据源验证。
- 检查 72,944 笔成交的费用与滑点归因。手续费最大差异 0.01 元，在 Python 与 NumPy 舍入及成交金额舍入差异的容差内；滑点归因仅有浮点误差。这验证记账计算，不证明实际市场能以模拟价格成交。
- 所有历史目标的信号日早于执行日。代码检查确认因子方向与定义一致，分组在剔除未来收益缺失值前形成；这不等同于完成股票池和全流程前视偏差审计。
- 45 组年度实验通过已有账务核验：净值组成、非负现金与持仓、交易日期、月收益复合及成本汇总。66 项项目测试通过。
- 五年结果记录的研究源文件校验值均与当前版本一致。

## 结果变化

| 年份 | 统一后主策略收益 | 最大回撤 | 费用及滑点 | 零交易成本收益 |
|---|---:|---:|---:|---:|
| 2016 | -13.64% | 30.42% | 159,786.81 元 | 5.76% |
| 2017 | -10.20% | 14.33% | 198,110.01 元 | 10.30% |
| 2018 | -43.59% | 44.97% | 162,706.70 元 | -29.96% |
| 2019 | -7.67% | 30.85% | 226,116.11 元 | 15.76% |
| 2020 | 3.47% | 14.65% | 225,941.77 元 | 29.37% |

2016—2019 各组收益均未变化。2020 主策略由 3.257483% 变为 3.465993%，增加 0.208510 个百分点；排名缓冲由 3.886410% 变为 4.043873%。本次统一采用既有的 0.5% 重大复权阈值，同时补齐历史代码别名涨跌停字段。未通过单独消融实验分离各项修正的收益贡献。

每年独立以 100 万元现金开始，不能拼成连续账户的多年收益。零交易成本情景会改变持仓与成交路径，其收益差也不能直接视为费用总额。

## 尚未解决的问题

重大未解释复权变化按年份分别为 10、5、0、6、2 项，共 23 项。2020 从旧口径的 145 项降至 2 项、隔离股票日从 2,900 降至 40，主要反映阈值口径变化，不能写成 143 项公司行动已经获得公告验证。2018 的登记也仍需区分最终实施公告与日程／年鉴推断证据。小于阈值的变化、历史股票池、停牌估值及公司行动日期仍有数据风险。

本次未发现入选因子的算术或费用记账错误；四年主策略亏损和 2018 零交易成本仍亏损的现象继续成立。下一阶段优先完成公司行动证据与股票池审计，再评估连续账户及预先登记的低换手方案。2021—2023 验证尚未完成，2024—2025 封存期未打开。当前不形成实盘交易清单。
