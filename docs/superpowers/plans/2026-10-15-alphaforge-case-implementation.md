# AlphaForge单案例实施计划

依据已批准的单案例范围和`2026-10-15-alphaforge-case-design.md`，2026-10-15实施。writing-plans专用技能在本机技能目录未找到，使用本文件明确步骤与验收，不宣称已调用该技能。

1. 核对进程、磁盘和旧数据。冻结完整数据manifest、metadata、core、旧960及Ridge463产物、原始论文与算子来源指纹。独立D盘目录与锁防重复运行。
2. 新增独立数学因子模块及边界测试：10点、单位、相关而非收益相关、epsilon、常量、缺行、调整变化、未来扰动；旧核心不变。
3. 新增本轮runner。读冻结common200，准备同池、原因子/负信号/三因子分数，生成IC与分层、两路径目标，冻结准备产物，然后六个真实股份账户。
4. 新增诊断模块与测试，验证标签缺失不改变分组、相关定义和常量空值。画诊断、分布、实际账户净值回撤；禁止复利标签冒充可交易组合。
5. 新增独立核验器，逐行重算数学式、目标选择、六账户权益和现金/应收/股份、跨年、收益、换手、成本与预登记关卡。核验器不调用新因子函数作为唯一证据。
6. 先跑新增单元测试，再运行准备/六账户，最后独立核验与图像检查。发现实现错误留失败日志，修正不改变冻结研究规则。通过后不无理由扩展训练或回测范围。
7. 保存报告、结论、进度及完整哈希清单；向用户报告课程复现和策略资格的分别状态。无论盈利与否，不将旧年份标成未见样本外、不连接券商。

并行分工：主代理负责设计、runner、运行和报告；因子代理仅新因子/测试；诊断代理仅新诊断/测试；账户代理仅新核验/测试。全数据任务由主代理串行调度避免重复。
