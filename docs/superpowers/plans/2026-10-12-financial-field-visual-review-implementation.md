# 固定原文财务字段视觉核验

持续目标下固定140键按报告期/代码排序，最多20键一批。逐键读取原年报候选中最早数字命中页及前一页，存原PDF/来源/图像哈希，只供人工核验，不自动批准。无原年报的上市前报告期可单列招股资料，不能把其公开日提前到报告期。

人工逐页确认当前目标年度、字段归属、单位、符号与金额；万元显示舍入不冒充精确元数。比较期或其他科目命中、后续版本、年份/单位缺失均明确标记待查，金额观察与历史可用仍分开。记录原文截图及修订状态，保留所有旧文档和实验。

物理页不猜测、固定队列不按收益挑选，原版本与更正版证据分列。不能用“verified_flag0_clear”机器旧名称当已核实可用。每批结果追加，候选渲染完成不等于审阅完成；未知保持false/null。
