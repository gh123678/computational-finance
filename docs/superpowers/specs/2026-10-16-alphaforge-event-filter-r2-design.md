# AlphaForge r2：原价参考与行动隔离方案（待用户审阅）

日期：2026-10-16。状态：仅提出规则修订，尚未批准，未实施r2因子或账户。r1保持原样和准备失败结论。

## 问题与本轮证据

r1在154个周度形成日中有四期未过200只门槛，原因是10日窗口内任何adj_factor精确变化都触发排除。数学实现及282,624条形成记录已独立核验；没有IC或六账户结果。

2026-10-16对四个失败日原池并集1,455只股票，在2018-08-01至09-10做42,195次相邻开市日核对。2,699次系数变化中，2,611次原价参考连续且无缓存行动匹配；87次参考价不连续并匹配已实施分红；1次缺相邻报价。无匹配不证明没有行动，原价参考连续不证明系数错误或只属舍入。供应商精度尚无通用官方规则支持，不能设0.0005容差或用08-28的恢复回填更早资格。

四期静态覆盖预览分别为1,353／1,250／1,211／1,178，只检验候选参考价与缓存行动条件，未读收益、未计算因子或交易。这不是r2已准备通过，也不是全部154期或历史版本可用性已获认证。

## 选择的方案与替代方案

**建议方案：保留原始价量和数学式，仅修订窗口断点排除。**因子不直接消费adj_factor，孤立的供应商系数变化转为审计标记；原价参考变更、已登记的生效行动与缺失参考仍隔离。原common200未知事件隔离不解除。

替代方案是把价格、量分别按adj_j/adj_t与其倒数统一到形成日基准。它会将有争议的系数直接引入特征，且现金分红也改变合成量；合成量并非真实成交股数，epsilon分支还受单位影响。本次不采用，也不在失败后切换。

另一选择是维持r1停止，等到取得可复核的供应商解释或独立历史资料后再议。不能把“未过200只”作为降低门槛或自动认定舍入的依据。

## r2唯一改动与固定输入

独立版本名为`alphaforge_case_2018_2020_r2`，证据存D盘，C盘仅作junction。r1、原始行情、旧账户、失败及所有清单不改写。r2先核验r1的63条与旧三套1,423条指纹，以及全部冻结行情、metadata和源码。

基础池仍是旧common200，评价2018—2020的154期原周历。窗口仍为形成日和之前9个开市日，共10点；OHLC、close、vol、amount、adj_factor原基础完整条件保留。因子用原始close元、vol×100股，不对价量作新的复权变换。

对窗口**内部**的9个相邻交易日转换，按以下确定顺序判断：

1. 缺任一报价、前一日close或当日pre_close，或参考价非有限正值，按`unknown_reference`排除；不前向填充、不跨停牌缺口。
2. 以原CSV字符串的Decimal数值比较当日pre_close与前一日close；不同即`raw_reference_change`排除。不新增小数位舍入、比例容差或0.0005阈值。
3. 既有事件登记中，现金分红、送转、配股及明确的参考价重置如在窗口内部生效，且实施公告／来源公开日期不晚于形成日，亦排除。使用既有已实施事件及有来源的纠正／配股登记，不新增猜测事件；事件生效日也必须不晚于形成日。公告／来源日期缺失、互相矛盾或晚于形成日的记录不作为“当时已知行动”参与历史选择，不用未来公告补全过去；另记`event_timing_unverified`覆盖风险。该标记不参与股票排序或资格，不能被解释为“无行动”；参考价条件仍独立执行。准备与最终报告必须列明未认证的事件时间范围，历史版本身份未获认证的限制始终保留。
4. 仅adj_factor变化、但以上未观测到断点时，保留原始数学输入并记录`isolated_factor_change_no_observed_reference_break`；此名称不认证舍入或无行动。

实施前冻结逐事件的`known_date`、具体字段／原文来源和选择理由：实施分红默认使用`imp_ann_date`，不能用更早的方案提案`ann_date`替代；配股或参考价重置使用已核验具体公告的发布日期。若改用明确原文替代缓存日期，必须逐事件列明证据及理由，不能按结果择早。URL中的日期或当前下载时间不能独自认证公开日；无法认证者一律`event_timing_unverified`。正常提案日与实施公告日不同不自动算矛盾。`known_date<=t`仅作日级过滤，不认证日内发布时间或不可修订的历史版本。

窗口首日以前的转换不额外纳入，否则变成11点要求；但原common200更长未知事件隔离完全保留。现有晚取得的历史字段和事件登记仍是回顾性输入，日期条件不能认证当时版本：本轮不恢复独立样本外或历史时点完整身份。

任何一期仍少于200只，或准备数据/时间规则无法按上述定义执行，即停止r2准备并保留证据；不跳期、不删失败日期、不切到调整价量替代方案。四期预览只是可行性线索，不代替完整准备核验。

## 全部保持不变的研究规则

`f=S_log1p(ts_min(ts_corr(close,volume,10),1))`；float64，原epsilon严格`<1e-6`时分母改1，不裁剪rho；常量0留为同分。唯一交易主信号仍`-f`，当期平均同分百分位排名，不运行反向账户。

两路径仍是负号案例主候选与同池旧三因子对照，各0／10／30bp共六账户；100万元，周末形成／下周首日执行，20只目标、单股4.9%、每行业最多5只、原0.05留仓差与每周5只主动替换、现金与容量限制、真实股数及分红配股账务均保持。无模型、风险覆盖或参数搜索。

D标签、形成后连接标签、固定五组、IC/RankIC与缺失规则不变。分组均值明确为未扣费超额，不复利标签冒充净值。实际净值只从股份账户生成。r1/r2共同有效的同一股票／形成日，原公式数值必须相同；股票池变化导致百分位变化须单独解释。

通过条件仍是：主10与30bp累计净收益>0，主10收益严格超过同池对照10，主10最大回撤≤25%，三年至少两年主10净收益为正，负号信号平均RankIC>0且至少两年平均RankIC>0。任一失败结案，不翻号、不扫窗口、不打开2021—2025救援。工程核验与策略资格分开，仍不接券商。
