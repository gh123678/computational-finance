# 最近报告期的证据覆盖审计

本轮按已确认10月7日财务审计设计与10月12日持续策略路线，检查2016—2020完整共同信号股票池的最近财报候选。这里只读取本地原始财务快照及信号代码/日期；不读取收益挑样本，不生成新因子、模型、训练或回测。当前策略仍不启用。

原始指标快照177,208行、2,912代码、88,686个代码/公告日/报告期键；按已批准2013—2020公告窗口保留171,408行、85,780键。未发现报告期晚于公告日的指标记录。查询终点20201231包含2021公告的原始响应仍保留，其内容不进入本诊断窗口。

251个信号日共有492,205条股票/日期记录。每一条仅确定最近可见报告键：公告日严格早于信号日，先取最大报告期，再取该报告期最大公告日；同一天竞争版本保留数量及差异，不选数值。信号日均核对为现有日历开市日，因此严格公告日不等式在这些信号截面具有公告后开市日的候选边界；仍不证明真实历史版本公开时间。

信号实际使用43,799个不同代码/公告日/报告期候选键，其中47键能够关联到本轮166键内容清单。这不是全部既存人工核验的覆盖汇总：32键切片、早期首尾样本及其他已审阅来源不在这个联结范围内，也不能随意相加。全部信号均有API候选，最近候选扣非没有全版本为空的情形，但API字段非空绝不等于原文和时点通过。

569条遮挡涉及57只股票。例如001965.SZ在2018-06-29及随后数次信号中，最近可见报告期为20180331，若只按最新公告批次则会指向20170930。该比较是本轮诊断构造的取数方式对照，不声称已冻结策略曾消费了错误财务值；旧候选公告年龄脚本本就只统计公告批次、没有选择财务值，旧结果未改。

本轮以独立直接比较方法复核全部492,205条：对每个股票的每个信号日，直接在所有原始日期键中计算可见最大报告期，再求该期最大公告日。该方法不调用生成事件状态的逻辑，也不使用其时间联结，结果逐条一致。181项项目测试通过、6项既存警告；新增回归覆盖后发旧报告不能遮挡新报告、同日禁止使用、最新期缺失不能退回旧值，以及竞争版本不能自动挑选。输入哈希未变、960个旧实验文件保持原指纹，140键补核验阶段459个产物指纹复核通过。

产物位于`output/latest_financial_report_coverage_20261012_r1/`：`required_latest_report_keys.csv`为43,799键范围清单，`signal_latest_report_evidence.csv.gz`为全部信号候选键与门槛状态，`older_report_shadow_details.csv`为569条差异明细，`yearly_summary.json`、`summary.json`及`independent_full_scope_verification.json`记录统计与独立复核。全部`usable_in_verified_history=false`，没有选择财务值或写入正式可用日。

下一步先将已有各范围证据按代码/公告日/报告期及PDF身份进行去重联结，核定尚未覆盖的原版本、完整后续报告与更正序列。若只能取得当前索引而无法支持历史版本，应如实给出数据可追溯性失败判断；不能用默认flag、统一延迟或保留过期报告的方式继续财务策略实验。
