# 第二版改进方案与验收

本轮针对用户“再去改进”及上一轮明确指出的P1接入偏轻量问题，增强工程接入证据，不更换研究结论或调参。原v1压缩包保留，v2另行交付。

选择：采用P1已有数据读取、登记式样本选择、目标表和结果表接口，新增月度因子执行适配器。另两条路线——只补文字说明，或强行把零投资/杠杆因子塞入A股股数引擎——分别不能解决实际接入与会改变经济规则，故不采用。

实际复用：从冻结P1源文件逐字节抽取read_market、dataset_config、summarize，连同既有attribution.py调用。记录完整源文件与函数段SHA，附冻结源文件供离线复核。summarize的252日年化输出不用于月数据，仅复用期间总收益、回撤、现金、费用和换手核对，年化仍由12期适配器负责。

新增接口：French数据适配为明确的因子观测表，经P1 read_market读入；登记主/后续样本；统一目标表保留signal_date、execution_date、ts_code、target_weight，严格验证形成日先于执行日；引擎按backend分发；输出与P1一致的nav/orders/holdings/corporate_events四表，以及P1原cost_breakdown和月度绩效。指数单位是研究记账单位，不伪造可交易股票或ETF。

验收：原研究主指标和全部11组后续账户在数值容差内与v1一致；所有13组实验必须经过适配器、实际调用P1函数、落盘完整证据；拒绝同日/未来形成、错月、重复和缺失目标；从导出的成交、现金和持仓反推净值与费用；最后重新生成报告、测试、清单、v2 ZIP并解压重跑。
